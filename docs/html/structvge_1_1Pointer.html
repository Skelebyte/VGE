Detailed Description

template<typename T>
struct vge::Pointer< T >

Wrapper for * types. Handles freeing memory automatically.

Warning
Do not use as a * (Pointer<...> *ptr;) unless you are going to free it manually.

Parameters

lineThe line this function was called on.

Example:

Pointer<float> ptr;
ptr.Malloc(3); // 3 floats allocated
// then do whatever. access `data` with `ptr[...]` or `ptr.GetData()`
// out of scope, the destructor is called automatically
ptr.~Pointer();
